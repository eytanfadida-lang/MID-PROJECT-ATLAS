# תוסף CRM לוואטסאפ ווב - שלב 1 (תצוגה בלבד)

## התקנה לבדיקה (לפני פרסום בחנות)

1. ב-Chrome: `chrome://extensions`
2. להפעיל "מצב מפתחת" (Developer mode) - מתג בפינה הימנית העליונה
3. "טעינת תוסף שלא נארז" (Load unpacked) → לבחור את התיקייה `extension/` הזו
4. ללחוץ על סמל התוסף בשורת הכתובת ולהתחבר עם שם המשתמש/סיסמה הרגילים מה-CRM
5. לפתוח web.whatsapp.com - פאנל אמור להיפתח בצד השמאלי

## מה יש בשלב הזה

תצוגה בלבד: הפאנל מזהה אוטומטית את מספר הטלפון של השיחה הפתוחה ומציג מידע מה-CRM (ליד,
סטטוס, סניף, הערות, מנוי מ-Arbox, ביקורים אחרונים). אין עדיין יצירת ליד/שינוי סטטוס/הוספת
הערה/תגובות מהירות - זה השלב הבא.

## אם הפאנל לא מזהה מספר טלפון אוטומטית

זה הסיכון הטכני הידוע מראש (ראו הערה ב-`content-world.js`): וואטסאפ לא חושפת API רשמי לקרוא
איזה צ'אט פתוח, אז התוסף "מתחבר" למבנה הפנימי שלה - ועלול לא לעבוד בדיוק מהניסיון הראשון, או
להפסיק לעבוד בעדכון עתידי של וואטסאפ ווב.

**אם זה קורה:** בפאנל עצמו תופיע תיבת "הכניסי מספר טלפון ידנית" כגיבוי - אפשר להמשיך לעבוד
דרכה. ולדיווח חזרה אליי כדי שאתקן:

1. לפתוח את כלי הפיתוח של הדפדפן (F12) בזמן ש-web.whatsapp.com פתוח
2. לעבור ללשונית Console
3. לחפש שורות שמתחילות ב-`[AtlasCRM]`
4. להעתיק אליי בדיוק מה שכתוב שם (בעיקר שורות עם "not found" או שגיאה אדומה)

## סטטוס פרסום

עדיין לא פורסם בחנות Chrome - כרגע רק "לא רשום" (unpacked) לבדיקה. פרסום פרטי/לא-רשום בחנות
(כדי שעדכונים יגיעו אוטומטית לכל העובדות) מתוכנן לשלב מאוחר יותר.
