# שער וואטסאפ "לא רשמי" (מכשיר מקושר)

תהליך Node.js קטן שמחבר חשבון וואטסאפ רגיל לאפליקציה בסריקת QR (כמו WhatsApp Web), על גבי הספרייה Baileys.
הוא רץ ברקע כ-**Always-on task** ב-PythonAnywhere ומדבר עם האפליקציה דרך HTTP מאובטח בטוקן:

- כל ~3 שניות הוא שואל את האפליקציה מה המנהלת ביקשה (חיבור / ניתוק / מחיקה), וזה גם ה"דופק" שלו.
- הוא מדווח לאפליקציה סטטוס, QR ומספר מחובר. האפליקציה מציגה אותם בעמוד **אינטגרציות**.
- ההתחברות לוואטסאפ נשמרת בתיקיית `auth/` (סודית, לא עולה ל-git). בלי ההתחברות הזו אפשר להשתלט על המספר - אל תשתפו אותה.

> חיבור לא רשמי נוגד את תנאי השימוש של וואטסאפ, ומספר שמחובר כך עלול להיחסם. חברו מספר משני.

## התקנה ב-PythonAnywhere (פעם אחת)

1. ב-Bash console, אחרי `git pull` בתיקיית הפרויקט (Node כבר מותקן עם nvm):

   ```bash
   cd ~/<תיקיית-הפרויקט>/gateway
   export PATH="$(ls -d ~/.nvm/versions/node/*/bin | tail -1):$PATH"
   npm install --omit=dev
   chmod +x run.sh
   echo "ATLAS_URL=https://<שם-המשתמש>.pythonanywhere.com" > .env
   ```

2. בדף **Tasks** ← **Always-on tasks** ← בשדה Run:

   ```
   bash /home/<שם-המשתמש>/<תיקיית-הפרויקט>/gateway/run.sh
   ```

   ולחצו Create. התהליך מתחיל מיד, ו-PythonAnywhere מרים אותו מחדש אם הוא נופל.

3. באפליקציה: **אינטגרציות** ← **חבר חשבון**. אחרי שהשירות פועל, האזהרה "שירות החיבור לא פועל" נעלמת.

הטוקן המשותף (`.gateway_token` בשורש הפרויקט) נוצר אוטומטית על ידי האפליקציה, והשער קורא אותו משם.

## עדכון

אחרי `git pull`: `npm install --omit=dev` (אם `package.json` השתנה), ואז בדף Tasks ללחוץ על **Restart** ליד המשימה.
ההתחברויות נשמרות, ולא צריך לסרוק שוב.

## לוגים ובעיות

- הלוג של המשימה מופיע בדף Tasks (קובץ ה-log שלידה).
- "poll failed ... HTTP 401": הטוקן לא תואם. ודאו שהשער והאפליקציה רצים מאותה תיקיית פרויקט (אותו `.gateway_token`).
- המכסה היומית של PythonAnywhere היא ב-CPU-seconds (חבילת Developer: 5,000 ליום, משותפת לכל המשימות). השער ברוב הזמן ממתין ולכן צורך מעט; אם המכסה נגמרת, המשימה מואטת.
- "הוסר מהטלפון": הסרתם את המכשיר ב-WhatsApp ← מכשירים מקושרים. לחצו "חיבור מחדש" וסרקו שוב.

## פיתוח מקומי

```bash
npm install
npm test                                   # בדיקות לולאת הסנכרון (בלי רשת)
ATLAS_URL=http://127.0.0.1:5000 GATEWAY_FAKE=1 node index.js   # מצב מדומה: QR מזויף שנסרק אחרי 15 שניות, בלי וואטסאפ
```

משתני סביבה: `ATLAS_URL` (חובה), `GATEWAY_TOKEN_FILE` / `GATEWAY_TOKEN`, `AUTH_DIR`, `POLL_MS`, `GATEWAY_FAKE`, `FAKE_SCAN_AFTER_MS`.
